# ParaWorld VPN · 平行世界

**看 YouTube、用 ChatGPT、查海外资料，让上网多一些选择。**

ParaWorld VPN（平行世界）帮助你连接海外网络，浏览海外网站、观看视频、使用海外 AI 工具。电脑、安卓手机都有专用客户端，选择线路，一键连接；iPhone、iPad 可搭配小火箭（Shadowrocket）或 Nextin 使用。

不懂技术也能开始，跟着下面的教程操作即可。遇到问题，可通过官网工单联系支持。

**[访问官网](https://paraworldlink.com)** · [入门指南](GETTING_STARTED.md) · [常见问题](FAQ.md)

## 开始使用

1. 打开 [ParaWorld 官网](https://paraworldlink.com)，注册并登录账户。
2. 在官网找到“全部客户端”，下载适合自己设备的客户端。
3. 按官网教程登录或导入订阅，选择线路并连接。
4. 连接成功后，打开需要访问的网站或服务。

套餐、试用与可用线路请查看官网当前显示的信息。

## 功能与使用说明

- 提供多个平台的客户端，方便在不同设备上使用。
- 可查看账户流量、套餐到期时间与线路状态。
- 桌面客户端提供智能路由（PAC）与全局模式，具体以对应平台版本为准。
- 使用中遇到问题，可通过官网工单联系支持。
