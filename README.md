# ParaWorld VPN · 平行世界

连接海外网络，从这里开始。

ParaWorld VPN 提供多平台客户端与订阅使用方式，方便用户访问海外网站、视频及在线服务。本仓库提供入门指南、常见问题和问题反馈入口。

## 开始使用

1. 打开 [ParaWorld 官网](https://paraworldlink.com)，注册并登录账户。
2. 在官网找到“全部客户端”，下载适合自己设备的客户端。
3. 按官网教程登录或导入订阅，选择线路并连接。
4. 连接成功后，打开需要访问的网站或服务。

套餐、试用与可用线路请查看官网当前显示的信息。

## 功能与使用说明

- 提供多个平台的客户端，方便在不同设备上使用。
- 可查看账户流量、套餐到期时间与线路状态。
- 桌面客户端提供智能路由（PAC）与全局模式，具体以对应平台版本为准。
- 使用中遇到问题，可通过官网工单联系支持。
